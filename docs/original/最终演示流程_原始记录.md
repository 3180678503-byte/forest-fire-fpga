# 最终演示流程

最终演示工程：`D:\Project\drone_project\integration\an5641_full_action_20261031`

功能：AN5641摄像头＋YOLO检测＋HDMI画面＋Action模拟动作＋Qwen v3真实复核＋ESP32无线控制。

## 1. 接线、上电

- AN5641保持接在Lite的J16。
- Lite HDMI接显示器；使用图传时，HDMI接机载图传，画面看地面屏。
- USB转TTL接Lite，TXD→ESP D16、RXD→D17、GND→GND；TTL电源脚不接。ESP自身USB可使用本次已验证的Lite供电接法，使用稳定线材和供电；电脑或独立USB电源作为备用。
- 开发板、ESP和显示设备上电。电脑保持联网，用于Qwen访问；日常控制无需网线。

2026-11-03已启用通信USB自动识别：程序优先尝试上次成功的端口，失效时通过ESP AT回应重新识别，不需要记USB接口或手动改绑定。实际接口可在网页板端状态communication_usb中查看；TXD/RXD/GND接法保持不变。

## 2. 打开控制页面

电脑登录Windows后，会在后台自动准备控制服务和已配置热点。日常不需要运行脚本，浏览器直接打开（建议收藏）：

`http://127.0.0.1:8770`

地址须包含端口`8770`。刚登录电脑时给后台服务约一分钟准备时间，网页短暂打不开可稍后刷新；服务退出后后台会重试恢复。网页中的“设备离线”表示ESP/开发板尚未连到控制服务，检查供电及电脑热点，等它自动连上。

等待“设备在线，可以选择并启动”。后台本身不启动板端推理；选择真实Qwen并启动后，候选裁剪图会上传云端复核，产生API调用费用。当前每次电脑服务启动的真实请求预算1000次。

电脑需保持开机并登录这个Windows账户。网页用于电脑本机控制；开发板和ESP仍需连到这台电脑的热点。

## 性能与Qwen展示（2026-11-03已上板）

仍打开8770，展开“演示控制”选择参数并保存启动；上方显示真实板端帧数、FPS和资源，右侧显示实际送审ROI与复核阶段。点击“大字演示”隐藏控制，适合与图传遥控器同时拍摄。数据过期时保留最后数值并标明过期。Qwen真实/模拟模式明确区分，合成链路测试图片另有标记。8771是开发合成预览，正式演示使用8770。NPU/采集独立耗时当前显示待测。

## 3. 设置并启动

页面设置一次：

| 项目 | 设置 |
|---|---|
| 运行模式 | 实时相机＋HDMI |
| Qwen | 真实Qwen；也可直接选关闭或模拟复核 |
| 冷却 | 10秒 |
| 检测阈值 | 0.25 |
| NMS IoU | 0.7 |

通信与检测已经分开管理：程序启动后，通信服务重启或短时离线，本地相机检测与HDMI继续运行；连接恢复后网页查询同一会话。“停止”结束检测，“保存并重启”创建新会话。开发板上电后仍通过网页启动。

点击“保存并启动”。网页先保存全部所选参数，收到板端成功确认后再启动，无需分别点保存。程序已运行时，用“保存并重启”应用修改。后台Qwen服务显示“网页选择”，不再需要脚本切换mock/remote。在HDMI画面确认：

- 摄像头画面随动作变化，FRAME持续增长。
- 有目标时出现fire/smoke检测框。
- 可见ACTION SIM状态与vx/vy/vz/yaw数值。

网页用于控制；摄像头画面在HDMI显示器或图传地面屏上。

## 4. 按这个顺序展示，约2—3分钟

### A. 连续画面

移动手或物体约10秒，展示画面流畅、帧号增长及无线查询状态。

### B. 火焰识别与复核

1. 将准备好的火焰测试视频放在摄像头画面中央，大小适中、清晰可见。
2. 素材摆好后，在网页点击“保存并重启”，开始这一段。
3. 保持位置15—20秒，展示fire框、ACTION SIM状态和Qwen提示。
4. 观察Qwen从pending到实际返回；回复通常需要几秒，具体结果以屏幕和日志为准。

### C. 烟雾识别与复核

换成烟雾测试视频，摆好后再次点击“保存并重启”，保持15—20秒，展示smoke框和复核结果。

### D. 目标移开

移开素材，观察目标丢失后的状态及动作建议归零。下一段演示仍采用“先摆好素材，再重启例程”的顺序，重置目标跟踪和动作状态。

演示目标放在画面中央，保持镜头与光线稳定。Action显示的是模拟建议，没有向飞控发送命令；Qwen显示语义复核建议，原YOLO框继续保留。

## 5. 结束

1. 网页点击“停止”，等待例程退出。电脑控制服务及热点继续待机，下次直接回到网页启动。
2. 需要关闭开发板时，通过已有串口或SSH执行`poweroff`，等系统关机后再断电。

电脑服务停止脚本仅用于维护，会停止本次登录会话的后台守护和控制服务；下次登录仍自动启动。永久关闭自动启动可运行`network/esp32_qwen_20261023/remote_control/scripts/disable_autostart.ps1`。后台会定期恢复热点，日常停推理只用网页“停止”。

## 6. 演示时只处理这几种情况

| 现象 | 操作 |
|---|---|
| 设备不在线 | 已启动的本地检测和HDMI继续运行；检查Lite/ESP供电、USB转TTL和电脑热点，恢复后查询原会话 |
| USB过流日志或集线器掉线 | 先正常关机，拔掉外接USB，断电10秒冷启动；只接回通信转串口，ESP保持独立供电，其他USB先不接 |
| 启动后没有实时画面 | 点“最近日志”；若有IIC NACK，断电检查摄像头排线/供电；同时核对HDMI线和屏幕输入 |
| 有框但暂时没有Qwen返回 | 目标保持稳定15—20秒，确认网页选真实Qwen且已保存并启动、电脑联网 |
| ACTION一直RETURN或动作值为零 | 素材先放好，再点“保存并重启”；动作是否非零还取决于目标状态 |
