# AI辅助使用说明

## 1. 本人工作与AI使用方式

本人负责森林火灾检测系统的板端部署与集成，工作包括平台接口适配、摄像头与显示联调、后处理优化、ESP32通信接入、运行测试及技术报告整理。

开发过程中使用OpenAI Codex辅助分析源码和日志、编写与修改部分代码及脚本、组织自动化测试、统计运行数据，并制作报告初稿和技术图表。本人提出功能需求与运行约束，提供工程资料和设备条件，完成实物操作、现场问题反馈与功能确认，并负责提交材料的核对。

## 2. 各环节的AI参与情况

| 工作环节 | 本人负责的任务 | AI辅助内容 |
|---|---|---|
| 平台部署与接口适配 | 组织板端部署，核对模块连接、输入输出及现场运行情况 | 分析模型接口与编译日志，辅助编写和修改适配代码、配置及部署脚本 |
| 摄像头、显示与通信联调 | 完成设备接线、供电、画面观察和通信功能确认，反馈实际故障现象 | 分析日志与源码，提出排查步骤，辅助修改采集、显示和通信程序 |
| 后处理与运行优化 | 明确优化目标，结合运行结果确认方案效果 | 分析阶段耗时，辅助实现候选DFL、局部绘图及相关工程修改 |
| 构建、测试与数据分析 | 提供测试条件、现场反馈，核对测试口径与功能表现 | 编写并执行部分构建、部署、自动化测试和统计脚本，整理输出对照与性能结果 |
| 报告与图表制作 | 确定个人贡献范围，核对技术描述、数据和图示 | 生成报告初稿、整理表格与排版，绘制系统框图、流程图和统计图 |

## 3. 工程验证与成果形成

工程修改的验证依据包括构建记录、固定输入输出对照、测试集推理结果、通信回归和现场运行反馈。性能与资源分析使用实际运行日志、采样文件及硬件工具报告，统计图依据对应数据绘制。

报告中的系统框图、硬件连接示意、处理流程和统计图由AI辅助制作；实物照片与运行截图来自实际设备和运行过程。本人负责核对图示与工程实现的一致性，并审核最终提交内容。

## 4. 作品运行中的大语言模型

作品接入Qwen执行异步语义复核，输入为检测目标的ROI图像，输出为结构化语义结果，用于辅助提示和事件记录。

Codex用于开发与材料整理，Qwen用于作品运行中的语义复核，两者分别承担上述任务。
